# 시각장애인 보행 안전을 위한 전동킥보드 점자블록 침범 방지 정책 제안

서울시 전동킥보드(PM) 견인 데이터를 분석해 점자블록 위 킥보드 방치를 줄이는 정책을 제안하는 데이터 분석 공모전 프로젝트입니다.

## 분석 구성

| 번호 | 분석 | 방법 | 결과 |
|---|---|---|---|
| 00 | 점자블록 견인 핫스팟·단속 캘린더 | 지번·법정동·자치구 집계, 음이항 회귀 | [00_hotspot/figures](00_hotspot/figures) |
| 01 | 상습 지번 재발 주기 | 생존분석 (Kaplan-Meier, 반복사건 Cox) | [01_recurrence/REPORT.md](01_recurrence/REPORT.md) |
| 03 | 과태료·신고포상금 금액 책정 | 기대처벌 모형, 손익분기·민감도 분석 | [03_penalty_model/REPORT.md](03_penalty_model/REPORT.md) |

## 핵심 결과

- **00 핫스팟:** 2025년 점자블록 사유 견인 1,420건 중 2회 이상 반복된 지번 214곳이 45%를 차지합니다. 상위 20개 법정동에 63%가 몰려 있고, 그중 8개 동에는 PM 주차구역이 한 곳도 없습니다.
- **00 주차구역 공백:** 동작구·관악구는 서울 점자블록 사유 견인의 28%를 차지하지만 PM 주차구역은 3%뿐입니다. 점자블록 견인의 39%가 주차구역이 한 곳도 없는 법정동에서 일어났습니다 (신림동 113건, 성내동·내발산동·장지동 각 36건 등).
- **00 단속 캘린더:** 점자블록 사유 견인의 99.9%가 평일에 처리됩니다. 주말·공휴일에는 보도 단속이 사실상 멈춥니다.
- **01 재발 주기:** 상습 지번 175곳에서 견인 후 재발까지 중앙값 **6일**, **14일 안에 80%** 가 다시 견인됩니다. 견인이 쌓여도 재발 간격은 길어지지 않습니다.
- **03 금액 책정:** 과태료 **2차 위반부터 10만 원, 3차 이상 20만 원**, 신고포상금 **과태료의 20%(건당 2만 원)에 상한**을 권합니다. 과태료 10만 원이면 위반 100건 중 1건만 추가로 신고돼도 억지력이 생깁니다.

## 원자료

**서울시 전동킥보드 견인 현황 (2025.1~12, 월별 시트)**

| 컬럼 | 내용 |
|---|---|
| 번호 | 월별 일련번호 |
| 신고일 | 신고 날짜 (조치일과 99% 이상 같은 날 → 견인일로 사용) |
| 구정보 | 자치구 |
| 주소 | 지번 주소 |
| 유형 | 위반 구분 (예: `점자블록 또는 교통약자 엘리베이터`) |
| 조치일 | 견인 처리 날짜 |

- 64,734건 (오신고 22건 포함, 분석에서는 제외)
- 정제 규칙 (손으로 고친 파일은 없음)
  - 각 시트 첫 행(빈 제목행) 건너뜀, 앞 6개 컬럼만 사용
  - 신고일·조치일에 날짜형과 문자열이 섞여 있어 날짜로 통일
  - `구정보` 컬럼이 일부 잘려 있어(예: `중구 신`) 구는 주소에서 다시 추출
  - 주소 공백 정리, `서울시 ` → `서울특별시 ` 통일
  - 같은 날·같은 주소 여러 행은 일괄 견인 기록이라 지우지 않음

**그 밖의 원자료**
- 서울시 전동킥보드 주차구역 현황 (329곳, cp949)
  - 230곳은 지번 주소에서 법정동을 바로 읽고, 도로명 주소 99곳은 행정안전부 주소정보누리집(juso.go.kr) 검색으로 법정동을 찾았습니다. 93개 주소 중 88개는 도로명·건물번호 정확 일치, 5개는 근거(같은 도로 인접 번호, 상세위치 건물)를 csv의 `근거` 열에 적었습니다.
- 기상청 종관기상관측(ASOS) 서울(108) 2025년 시간자료 (cp949)
- 공휴일: Python `holidays` 패키지 (대한민국 공휴일·대체공휴일·임시공휴일)

출처: 서울 열린데이터광장 「서울시 전동킥보드 견인 현황」·「서울시 전동킥보드 주차구역 현황」, 기상청 기상자료개방포털

## 실행

```bash
pip install -r requirements.txt

# 00 핫스팟·단속 캘린더
# (선택) 주차구역 도로명 주소 → 법정동 다시 조회: python 00_hotspot/lookup_parking_dong.py
python 00_hotspot/hotspot_analysis.py
python 00_hotspot/enforcement_calendar.py

# 01 재발 주기
cd 01_recurrence/src
python 01_load_data.py
python 02_select_lots.py
python 03_survival_analysis.py
python 04_figures.py
python 05_enforcement_pattern.py
cd ../..

# 03 과태료·포상금 (가정값만 사용)
python 03_penalty_model/src/deterrence_model.py
```

- 그림의 한글 폰트는 각 스크립트(00은 파일 상단, 01은 `src/config.py`)의 `FONT_PATH`에서 바꿀 수 있습니다. 경로가 없으면 Windows 기본 폰트(Malgun Gothic)를 씁니다.
