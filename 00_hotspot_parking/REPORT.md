# 점자블록 견인 핫스팟, 단속 캘린더, 주차구역 공백 분석

> 서울시 PM(전동킥보드) 견인 데이터 2025, 점자블록 사유 견인 1,420건, PM 주차구역 329곳

## 요약

점자블록 사유 견인은 소수 지번과 소수 자치구에 몰려 있습니다. 2회 이상 반복된 지번 214곳에서 전체 견인의 45퍼센트가 나왔고, 상위 20개 법정동에 63퍼센트가 몰려 있습니다. 견인의 99.9퍼센트는 평일에 처리되어 주말, 공휴일에는 단속이 사실상 멈춥니다. 점자블록 견인의 39퍼센트는 PM 주차구역이 한 곳도 없는 법정동에서 발생했습니다.

## 1. 분석 목적

점자블록 위 전동킥보드 방치를 줄이려면 가장 조치가 최우선인 지역과 적발 시간대을 파악하기 위해 분석을 시작했습니다. 견인이 얼마나 소수 지점에 몰려 있는지, 단속이 비는 시간대가 언제인지, 주차구역 부족이 견인 발생과 어떤 관계가 있는지를 차례로 살펴봤습니다.

## 2. 분석 데이터

| 항목 | 내용 |
|---|---|
| 원자료 | 서울시 전동킥보드 견인 현황 2025.1~12 (2개 파일, 월별 시트) |
| 원자료 | 서울시 전동킥보드 주차구역 현황 (329곳) |
| 원자료 | 기상청 ASOS 서울 2025년 시간자료 |
| 전체 견인 건수 | 64,712건 (오신고 22건 제외) |
| 점자블록 사유 견인 | 1,420건 |
| 점자블록 견인 지번 수 | 993곳 (지번 주소가 있는 건만) |

유형에 점자가 들어간 건을 점자블록 사유 견인으로 파악합니다. 점자블록과 교통약자 엘리베이터가 한 유형 코드로 묶여 있어, 이 수치는 점자블록 침범 건수의 상한으로 해석해야 합니다.

## 3. 분석 방법

### 3-1. 반복과 집중 측정

지번, 법정동, 자치구 단위로 점자블록 견인을 집계했습니다. 지번별 반복 횟수를 세고, 견인이 소수 지점에 얼마나 몰려 있는지는 로렌츠 곡선으로 측정했습니다. 로렌츠 곡선은 견인이 많은 지번부터 누적해 나갈 때, 지번 비율과 견인 비율이 얼마나 차이 나는지 보여주는 방법입니다. 연간 견인이 300건 미만인 구는 단속이 거의 운영되지 않는 것으로 보고 비교에서 제외하고, 단속 공백 지역으로 별도 표시했습니다.

### 3-2. 단속 시간 패턴 추정

평일 243일의 일별 점자블록 견인 건수를 대상으로, 요일, 강수, 폭염, 적설, 기온이 견인 건수에 미치는 영향을 음이항 회귀분석으로 추정했습니다. 같은 분석을 전체 견인 건수에도 동일하게 적용해 비교함으로써, 단속 강도 자체가 달라져서 생기는 수치 변화를 가려냈습니다. 비가 없는 평일을 기준으로 월별, 요일별 예측 견인 건수를 산출해 단속이 집중되어야 할 시기를 정리했습니다.

### 3-3. 주차구역 공백 측정

PM 주차구역 329곳을 법정동 단위로 배정하고 동별 점자블록 견인 건수와 결합했습니다. 동 안에 있는 주차구역 수를 0곳, 1에서 2곳, 3곳 이상 세 구간으로 나누어 구간별 견인 비중을 비교했습니다. 자치구 단위로는 주차구역 1곳당 점자블록 견인 건수를 계산해 자치구별 부족 정도를 비교했습니다.

## 4. 분석 결과

### 4-1. 반복과 집중

점자블록 견인이 나온 993개 지번 중 214곳(22퍼센트)에서 2회 이상 견인이 반복되었고, 이 지번들이 전체 견인의 45퍼센트를 차지했습니다. 상위 10퍼센트 지번이 전체의 29퍼센트를, 상위 20개 법정동이 63퍼센트를 차지했습니다.

### 4-2. 자치구 비교

관악구(198건)와 동작구(192건)가 전체 점자블록 견인의 27퍼센트를 차지해 가장 많았습니다. 연간 견인이 300건 미만이어서 비교에서 제외한 구는 성북구, 동대문구, 종로구, 강북구, 중랑구, 광진구, 성동구 7곳입니다. 이 구들은 단속이 운영되지 않는 것으로 보고 단속 공백 지역으로 분류했습니다.

### 4-3. 단속 시간 패턴

점자블록 견인 1,420건 중 1,419건이 평일에 발생했습니다. 토요일, 일요일, 공휴일을 합친 121일 동안 발생한 점자블록 견인은 1건입니다. 월별로는 5월부터 8월까지 넉 달 동안 전체의 약 41퍼센트가 집중됐습니다.

음이항 회귀분석 결과, 전체 견인은 요일이 지날수록, 비가 많이 올수록 뚜렷하게 줄어드는 패턴이 통계적으로 확인되었습니다. 다만 점자블록 사유 견인만 따로 보면 같은 방향의 경향은 있었지만 표본 수가 적어 통계적으로 뚜렷하게 확인되지는 않았습니다. 이 결과로 비가 없는 평일을 기준으로 한 월별, 요일별 예측값을 산출해 단속 우선순위를 매기는 캘린더를 제작했습니다.

### 4-4. 주차구역 공백

PM 주차구역 329곳 중 230곳은 지번 주소로, 99곳은 도로명 주소 조회로 법정동을 확인했습니다. 점자블록 견인이 1건 이상 있었던 법정동을 기준으로 보면, 주차구역이 한 곳도 없는 65개 동에서 전체 점자블록 견인의 39퍼센트(560건)가 발생했습니다.

자치구 단위에서는 동작구가 주차구역 1곳당 점자블록 견인 64건, 관악구가 40건으로 가장 높았습니다. 두 구 모두 점자블록 견인 비중에 비해 주차구역 비중이 크게 낮았습니다.

## 5. 한계

- 견인 기록은 실제 위반 건수가 아니라 처리 실적입니다. 신고되지 않고 방치된 건은 집계에 잡히지 않습니다.
- 점자블록과 교통약자 엘리베이터가 같은 유형 코드로 묶여 있어, 점자블록 단독 침범 건수와는 차이가 있을 수 있습니다.

## 6. 재현 방법

```bash
# 저장소 최상위에서
pip install -r requirements.txt

# (선택) 주차구역 도로명 주소를 법정동으로 다시 조회
python 00_hotspot_parking/lookup_parking_dong.py

# 핫스팟, 주차구역 공백
python 00_hotspot_parking/hotspot_analysis.py

# 단속 캘린더
python 00_hotspot_parking/enforcement_calendar.py
```

- 입력: `data/raw/`의 2025년 견인 원자료 2개, 주차구역 현황 csv, 기상청 ASOS 서울 시간자료. 받은 파일명 그대로 둡니다.
- 결과: `00_hotspot_parking/results/hotspot_summary.xlsx`, `calendar_summary.xlsx`, `figures/`
- 그림의 한글 글꼴은 각 스크립트 상단의 `FONT_PATH`에서 바꿀 수 있습니다. 경로가 없으면 Windows 기본 글꼴(맑은 고딕)을 씁니다.
