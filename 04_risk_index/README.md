# 전동킥보드 점자블록 방해 — 자치구 위험지수

서울 25개 자치구의 전동킥보드 주차로 인한 점자블록 방해 위험을 공공데이터만으로 비교하는 지수입니다.
(교통 공모전 분석 3·4: 주차구역 공백, 위험지수/시범 자치구 선정)

## 지수 구성

종합 위험지수 = 4개 변수 점수(0~100)의 가중 평균. 높을수록 위험.

| 축 | 변수 | 정의 | 방향 |
|---|---|---|---|
| 위해 | H1 점자블록 견인 지수 | 점자블록 견인 ÷ 기대 건수(같은 달 도시 평균 비율 적용), 표본 보정 | + |
| 위해 | H2 상습 지점 비중 | 점자블록 견인 중 같은 달 같은 주소 2건+ 비중, 표본 보정 | + |
| 취약성 | V1 시각장애인 수 | 구별 시각장애인 수 | + |
| 대응 공백 | G1 주차구역 밀도 | 주차구역 수 ÷ 월평균 견인 × 100 | − |

가중치는 변수별 동일(0.25). 전문가 판단(AHP)을 받을 수 없어 우열을 두지 않는 중립 가정이며,
CRITIC·엔트로피·시나리오·가중치 5,000회 무작위 변동으로 교차검증합니다.

### 자료 공백 처리
- **유효 월**: 그 달 견인이 해당 구 최대 월의 25% 이상인 달만 사용 (신고가 사실상 중단된 달 제외)
- **같은 달 비교**: 월별 도시 평균 점자블록 비율로 기대 건수를 계산해 분류 체계 변경·기간 차이를 완화
- **경험적 베이즈 보정**: 점자블록 견인 건수가 적은 구를 도시 평균 쪽으로 약하게 당김 (H1 감마-포아송, H2 베타-이항, 모수는 주변우도로 추정)
- 자료 신뢰도 등급은 쓰지 않고 표본 크기(n)를 그대로 표시

## 실행

```bash
pip install -r requirements.txt
python run_all.py
```
인자 없이 `data/` 폴더의 원자료를 읽어 `results/`에 결과를 저장합니다 (Python 3.10+). 입력 파일 설명은 `data/README.md` 참고. 그림의 한글 폰트는 Noto Sans CJK / 맑은 고딕 / AppleGothic / NanumGothic 중 설치된 것을 씁니다.

## 구조

```
run_all.py          파이프라인 진입점
src/config.py       가중치, 절사 비율, 유효 월 임계값
src/load_data.py    원자료 읽기
src/risk_index.py   변수 계산, 점수화, 종합지수
src/sensitivity.py  시나리오, 몬테카를로, 상관·VIF
src/figures.py      PNG 4장
results/            결과 CSV와 PNG
```
