# 전동킥보드 점자블록 방해 — 자치구 위험지수 (2025)

서울 자치구의 전동킥보드 주차로 인한 점자블록 방해 위험을 공공데이터만으로 비교하는 지수입니다.
**분석 기간: 2025년 1~12월.** (교통 공모전 분석 3·4: 주차구역 공백, 위험지수/시범 자치구 선정)

## 지수 구성

종합 위험지수 = 4개 변수 점수(0~100)의 가중 평균. 높을수록 위험.

| 축 | 변수 | 정의 | 방향 |
|---|---|---|---|
| 위해 | H1 점자블록 견인 지수 | 점자블록 견인 ÷ 기대 건수(같은 달 도시 평균 비율 적용), 표본 보정 | + |
| 위해 | H2 상습 지점 비중 | 점자블록 견인 중 같은 달 같은 주소 2건+ 비중, 표본 보정 | + |
| 취약성 | V1 시각장애인 수 | 구별 시각장애인 수 | + |
| 대응 공백 | G1 주차구역 밀도 | 주차구역 수 ÷ 월평균 견인 × 100 | − |

가중치는 변수별 동일(0.25). 전문가 판단(AHP) 전의 중립 가정이며,
CRITIC·엔트로피·시나리오 14개·가중치 5,000회 무작위 변동으로 교차검증합니다.

### 자치구·자료 선정
- **분석 대상 구**: 2025년 월평균 견인이 50건 미만인 구는 견인 사업이 사실상 운영되지 않은 것으로 보고 제외 (9개 구: 광진·성동·중랑·강북·동대문·종로·성북·용산·중구, 모두 월평균 32건 이하. 남은 16개 구는 최소 84건)
- **유효 월**: 그 달 견인이 해당 구 2025년 최대 월의 25% 이상인 달만 사용 (신고가 사실상 끊긴 달 제외)
- **같은 달 비교**: 월별 도시 평균 점자블록 비율로 기대 건수를 계산
- **경험적 베이즈 보정**: 점자블록 견인 건수가 적은 구를 도시 평균 쪽으로 약하게 당김 (H1 감마-포아송, H2 베타-이항, 모수는 주변우도로 추정)

### 동 단위 주차구역 공백
점자블록 견인을 법정동별로 집계하고 주차구역 수와 비교합니다. 주차구역 329곳 중 도로명 주소 99곳은
`data/processed/주차구역_도로명주소_법정동.csv`로 법정동을 채웠습니다 (보완 전/후를 모두 저장).

## 실행

```bash
pip install -r requirements.txt
cd 04_risk_index
python run_all.py
```
인자 없이 실행하면 **저장소 공용 `data/` 폴더**의 원자료를 찾아 읽고 `04_risk_index/results/`에 결과를 저장합니다 (Python 3.10+).
그림의 한글 폰트는 맑은 고딕 / Apple SD Gothic Neo / Noto Sans CJK / NanumGothic 중 설치된 것을 씁니다.

### 입력 데이터 (공용 폴더)

| 위치 | 파일 (이름 규칙) | 출처 |
|---|---|---|
| `data/raw/` | `*견인*.xlsx` — 서울특별시 전동킥보드 견인 현황 2025년 1~6월, 7~12월 (월별 시트) | 서울 열린데이터 광장 |
| `data/raw/` | `*장애인*.csv` — 서울시 장애인 현황(장애유형별·연령별) 2025 | 서울 열린데이터 광장 |
| `data/raw/` | `*주차구역*현황*.csv` — 서울시 전동킥보드 주차구역 현황 (329곳, cp949) | 서울 열린데이터 광장 |
| `data/processed/` | `주차구역_도로명주소_법정동.csv` — 도로명 주소 주차구역 99곳의 법정동 보완표 | 팀 작성 |

- 견인 현황 xlsx는 여러 개를 모두 합친 뒤 2025년 행만 씁니다(다른 연도 파일이 같이 있어도 됨). 유형에 "점자"가 들어간 건을 점자블록 견인으로 봅니다.
- 파일 위치나 이름이 다르면 `src/config.py`의 `INPUT_PATTERNS`를 고치거나 명령줄 인자로 지정합니다:
  `python run_all.py --tows "경로/*.xlsx" --disability 경로.csv --parking 경로.csv --dong-map 경로.csv`

## 한계

- 견인 건수는 실제 점자블록 방해 건수가 아니라 단속·신고 처리 실적입니다.
- 9개 구는 2025년 견인 기록이 거의 없어 판단할 자료가 없습니다(위험이 낮다는 뜻이 아님).
- 노출 축(보행 수요, 시설 근접도)과 점자블록 연장 자료가 없어 지수에 포함하지 못했습니다.
- 서대문(12건)·강남(1건)·도봉(30건)은 점자블록 견인 표본이 작아 불확실성이 큽니다. 강남구는 전체 견인 13,308건 중 점자블록 사유가 1건뿐이라 구마다 사유를 다르게 기록했을 가능성이 있습니다.
- 영등포구는 주차구역 파일에 없어 G1이 0으로 들어갑니다(실제 없음인지 미공개인지 불명).
- V1에는 구 인구 규모의 영향이 섞여 있습니다.
- 오신고 22건은 기본 설정에서 포함합니다. 빼려면 `src/config.py`에서 `EXCLUDE_TYPES = ["오신고"]`.
